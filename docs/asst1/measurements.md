# Assignment 1 · Measurements

## Timing method

Unless noted otherwise, results use default CPU scheduling.

- P1 and P3–P5: median of three program runs. Each run reports its best internal repetition: five in P1, three in P3–P5. P1's total includes worker printing.
- P6: median of three complete algorithm runs, excluding data loading. Phase timings come from separate profiling runs.

P5 uses single-core ISPC as its baseline; the other timed programs use serial code.
